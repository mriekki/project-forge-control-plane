# Disposable generation handoff proof

The prospective source transport proof and target publication proof are
separate. A successful source checkout is not permission to generate or
publish a Project. A local generated workspace is not remote acceptance.

This dormant helper qualifies the exact generated inventory (bytes and Git
executable modes), fixed synthetic approved manifest, explicitly selected
schema-v2 profile baselines, copy, stage, commit, local-only bare Git remote
and fresh clone. It refuses ignored artifacts, unexpected manifest changes,
case collisions, symlinks, bytecode and clean-filter or EOL drift. It accepts
no target URL or actual target checkout. Test fixtures contain no FMP data,
provider credentials or real application state. The synthetic remote is
deleted at completion and the generated input is preserved.

Use only **after** independently verified Bootstrap source and exact package
archive acquisition, with all source credentials revoked and no target
credential present. The selected package version, integrity and profile must
come from independently accepted policy, not the generated workspace.
Hosted unit tests prove the local handoff mechanics only. Actual protected
source-only transport and separately reviewed disposable GitHub target
publication remain required. The current remote generation handler still
rejects optional profiles; this helper does not bypass that contract or
authorize household/feedback generation. No changes to active generation,
Adoption, or Production.
